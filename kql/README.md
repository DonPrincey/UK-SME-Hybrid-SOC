# KQL Query Library

This folder contains Kusto Query Language queries developed for
Microsoft Sentinel monitoring, incident investigation and threat hunting.

## Planned query categories

- Authentication and sign-in activity
- Identity investigations
- Windows security events
- Sysmon endpoint activity
- Suspicious PowerShell execution
- Network connections
- Privilege escalation
- Lateral movement
- Data staging and exfiltration
- Incident and entity correlation

## Query documentation standard

Each query will include:

- Query name
- Investigation purpose
- Required data source
- KQL query
- Expected results
- MITRE ATT&CK mapping
- False-positive considerations
- Investigation notes
