# Beacon Professional Services Ltd

## Fictional Organisation Profile

## Organisation overview

Beacon Professional Services Ltd is a fictional UK-based
small-to-medium-sized organisation providing business, administrative
and technology services to commercial customers.

The company employs approximately 200 people and operates through a
combination of office-based, hybrid and fully remote working.

The organisation depends on Microsoft 365, Microsoft Azure, Windows
endpoints, Windows Server, Active Directory, Linux systems and remote
access services to support its daily operations.

## Organisation facts

- **Organisation name:** Beacon Professional Services Ltd
- **Organisation type:** UK professional and technology services SME
- **Number of employees:** Approximately 200
- **Primary location:** United Kingdom
- **Working model:** Office-based, hybrid and remote
- **Security team:** Limited internal security capability
- **Main cloud provider:** Microsoft Azure
- **Productivity platform:** Microsoft 365
- **Identity environment:** Active Directory and Microsoft Entra ID

## Business services

Beacon Professional Services Ltd provides the following services:

- Managed administrative support
- IT support and consulting
- Business-process services
- Customer account management
- Project and technical support

These services require employees to regularly access customer records,
project documentation, internal systems, shared files and Microsoft 365
services.

## Information handled by the organisation

Beacon Professional Services Ltd stores and processes:

- Customer records
- Employee personal information
- Commercial contracts
- Internal financial information
- Microsoft 365 email
- Project files
- Help-desk and service-request records
- Customer account information
- Internal operational documentation

## Technology environment

The organisation uses:

- Microsoft 365 for email, collaboration and document sharing
- Microsoft Entra ID for cloud identity and authentication
- Active Directory for on-premises identity management
- Windows endpoints for employees
- Windows Server for internal business services
- Linux servers for selected technical services
- Microsoft Azure for cloud-hosted systems and monitoring
- Virtual private network access for remote workers
- Remote support tools for IT and help-desk personnel
- Shared folders and cloud-based project storage

## Users and access

The environment is accessed by:

- Office-based employees
- Hybrid employees
- Fully remote employees
- IT support personnel
- System administrators
- Managers
- Customer-account staff
- Project and technical teams

Some users require privileged access to support systems, manage accounts
and maintain business services.

## Existing security challenges

The organisation has:

- A limited internal security team
- No dedicated 24-hour Security Operations Centre
- Limited centralised log monitoring
- Inconsistent incident-escalation procedures
- Limited visibility across endpoints, identities and network activity
- Dependence on remote access and cloud services
- A need for improved security documentation
- No fully tested incident-response runbooks

## Recent security concerns

The organisation has recently experienced:

- Increased phishing emails
- Repeated failed authentication attempts
- Possible password-spraying activity
- Suspicious user-account access
- Unusual PowerShell execution
- Concerns about privileged-account misuse
- Concerns about unauthorised access to sensitive files
- Possible attempts to stage and remove business data

## Relevance to Project Beacon

The organisation provides a realistic environment for investigating:

1. Password spraying against Microsoft Entra ID or Active Directory
2. Phishing followed by suspicious PowerShell activity
3. Privilege escalation and lateral movement
4. Data staging and attempted exfiltration

These scenarios are relevant because Beacon Professional Services Ltd
depends on user accounts, remote access, Microsoft 365, shared project
files and systems containing customer and employee information.

A successful compromise could affect:

- Customer confidentiality
- Employee privacy
- Business operations
- Contractual obligations
- Financial information
- Organisational reputation
- Regulatory and data-protection responsibilities

## Project justification

Project Beacon will design and demonstrate a practical hybrid Security
Operations Centre and incident-response programme for Beacon
Professional Services Ltd.

The project will improve visibility across identity, endpoint, server
and network activity by using Microsoft Sentinel, KQL, Windows security
events, Sysmon, Linux logs and network intrusion-detection alerts.

It will also introduce documented detection rules, investigation
procedures, escalation guidance, incident-response runbooks and
business-facing security reports.
