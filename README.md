# UK-SME-Hybrid-SOC
A portfolio project simulating a hybrid Security Operations Centre for a UK SME using Azure, Microsoft Sentinel, KQL, threat detection, incident investigation, runbooks and executive reporting.

## Project Beacon

Project Beacon is the flagship practical programme within this
repository.

It simulates the design and operation of a hybrid Security Operations
Centre and incident-response capability for Beacon Professional
Services Ltd, a fictional UK SME employing approximately 200 people.

The project will combine Microsoft Azure, Microsoft Sentinel, KQL,
Windows security telemetry, Sysmon, Linux logging and network
intrusion-detection evidence.

## Planned incident scenarios

1. Password spraying against Microsoft Entra ID or Active Directory
2. Phishing followed by suspicious PowerShell activity
3. Privilege escalation and lateral movement
4. Data staging and attempted exfiltration

## Ethical and legal boundary

All technical activity will be conducted only in authorised laboratory
environments.

Beacon Professional Services Ltd, its users and its security incidents
are fictional.

No public, employer, university, customer or third-party system will be
tested without explicit permission.
